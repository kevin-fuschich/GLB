GLB CLUB PAGE SPECIFICATION

Version: 1.0
Status: LOCKED
Applies to: All club-[city].html pages

⸻

Purpose

The Club Page exists to explain why a team exists, not how it performs.
	•	Team Record pages show outcomes.
	•	Club Pages show origin, culture, material, and place.
	•	The page should feel like a museum placard, not a brand site.

If a page feels promotional, emotional, or flashy — it is wrong.

⸻

Page Structure (Fixed)

Every Club Page must contain the following sections, in this order:
	1.	Header
	2.	Identity
	3.	Grounds
	4.	Tradition
	5.	Timeline
	6.	Record Reference (Footer)

No additional sections are permitted.

⸻

Header Rules

Title
	•	H1: City name only
	•	Correct: Toledo, Vancouver, San Pedro
	•	Incorrect: Toledo Vulcans, Vancouver Current

Established Line
	•	Format:
Est. [Year] • [Region/Country]
	•	Typography:
	•	Sans-serif
	•	11px
	•	Uppercase
	•	letter-spacing: 2px
	•	Separator must be &bull;

⸻

Image Philosophy (MANDATORY CHOICE)

Each club must commit to one image mode.
Mixing modes is forbidden.

Images must never feel like marketing assets.
They are evidence, not decoration.

Option A — The Mark (Authority)

Used for clubs claiming institutional legitimacy.
	•	Visual: Vector seal, stamp, geometric insignia
	•	Class: .club-mark
	•	Width: 70px
	•	Format: SVG preferred
	•	Example: San Pedro

⸻

Option B — The Archive (Evidence)

Used for clubs grounded in geography or transit.
	•	Visual: Documentary photography
(harbors, rail, streets, infrastructure)
	•	Tone: Muted, desaturated, or B&W
	•	No action shots. No people posing.
	•	Class: .club-artifact
	•	Width: 100px
	•	Format: JPG or PNG
	•	Example: Vancouver

⸻

Option C — The Artifact (Material)

Used for clubs defined by industry or physical labor.
	•	Visual: Macro texture
(steel, rust, concrete, wood, paint)
	•	Must be abstract but recognizable
	•	Class: .club-artifact
	•	Width: 100px
	•	Format: JPG or PNG
	•	Blend mode allowed: mix-blend-mode: multiply
	•	Example: Toledo, Birmingham

⸻

Writing Guidelines

Voice
	•	Write like a historian, not a hype man
	•	Neutral, declarative, grounded
	•	No adjectives that sell emotion

Language Rules
	•	Refer to “the club” (lowercase c) in narrative text
	•	Use concrete nouns:
	•	steel, fog, rail, sugar, water, heat
	•	Avoid abstractions:
	•	passionate, electric, iconic, world-class

⸻

Typography & Punctuation
	•	Smart quotes are mandatory
	•	Use “ ” and ‘ ’ — never straight quotes
	•	Periods go inside quotation marks
	•	Correct: “The House That Sugar Built.”
	•	Serif for narrative
	•	Sans-serif for metadata and labels

⸻

Section Requirements

1. Identity

Must answer:
	•	Why does this club exist here?
	•	Where does the name come from?
	•	What physical or cultural logic defines it?

⸻

2. Grounds

Must include:
	•	Venue name (bold)
	•	Location line (sans-serif, uppercase)
	•	Description focused on:
	•	Light
	•	Air
	•	Sound
	•	Physics
	•	Architecture

Never include:
	•	Capacity
	•	Amenities
	•	Fan experience language

⸻

3. Tradition

Define the club’s philosophy as an inheritance.
	•	How does the city’s character appear on the field?
	•	What is valued more than flash?

⸻

4. Timeline
	•	Unordered list (ul)
	•	Two-column grid:
	•	Year column: 110px, white-space: nowrap
	•	Event description
	•	3–5 entries maximum
	•	Focus on eras and origins, not championships

⸻

5. Record Reference (Footer)

Fixed copy:

“Official Statistics & Roster available in Team Record”
	•	Centered
	•	Sans-serif
	•	Quiet
	•	Must link to:
team-[city].html

⸻

File Naming (Strict)
	•	Club Page: club-[city].html
	•	Image: club-[city]-[type].[ext]
	•	Examples:
	•	club-vancouver-archive.jpg
	•	club-toledo-artifact.png
	•	club-san-pedro-mark.svg

Files live in the GLB root unless otherwise specified.

⸻

Non-Negotiables
	•	No logos beyond the selected image mode
	•	No color beyond the single club accent
	•	No UI elements that suggest interaction
	•	No deviation without updating this spec

If a choice isn’t covered here, don’t invent one.

⸻

End of Specification — v1.0
