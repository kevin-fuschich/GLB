# Legacy GLB data

These are historical copies of roster drafts and a player-game stat row from a matchup absent from the official Opening Day. The active rosters are `data/rosters/`; official games are `data/games/YYYY-MM-DD/*.json`. Do not use these archived files for standings, simulation, player identities, or season statistics.

Original filenames and contents are preserved under their former paths within this archive, including one malformed `.json` file and one `.jsbon` filename. They remain readable as history, not league records.
