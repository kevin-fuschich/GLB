# DONK base set

Twenty distinct driver photographs, generated with the built-in image tool from the existing driver/build references. Per-image subject prompts, source references, canonical driver claim IDs, and DB-001–DB-020 numbering are in `data/events/donk-base-cards.json`.

Shared prompt: a vertical 4:5 candid documentary photograph, ordinary ambient light, natural skin and anatomy, restrained color and slight analog grain. Capture an unplanned moment between runs rather than a staged portrait. Preserve the established driver and vehicle; avoid folded-arm poses, elbows on windows, cinematic smoke, HDR, added trophies and graphic overlays. The photo alone is generated; the consistent teal/cream physical card treatment and all printed labels are HTML/CSS.

Michael Bonnehomme's selected image is the outside-the-car replacement: a lean driver with glasses reviewing a timing slip, with the compact red/aqua Citation behind him. The through-windshield attempt was rejected and is not published. His corrected premium card also uses the compact Citation. Daryl Deez is an older, stockier driver with a salt-and-pepper beard.

The eight existing D26 cards form the 2026 Road to Tijuana subset. The base set includes all eight drivers plus twelve other unique club drivers, including Mavis Quill; Toi Boi Roi appears once in the base set. Editions share each driver's existing artifact ID so they cannot acquire conflicting owners. Championship outcomes remain in the 2026 event record; base cards do not create new results.
