# GLB — Source of Truth

## Primary Authority
Official box scores are the sole authoritative source for:
- Wins and losses
- Runs scored
- Runs allowed
- Player appearances

## Derived Pages
Team Record Pages derive data from:
- Official box scores only

They do not originate data.

## Prohibited Actions
- Manual stat editing
- Retrospective interpretation
- Narrative overrides

## Error Handling
If an error exists:
- Correct the box score
- Allow derived pages to reflect the correction

## Philosophy
GLB does not explain results.
GLB records them.

## Status
Enforced.
